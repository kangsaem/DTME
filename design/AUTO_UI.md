# AUTO 창 · 프리셋 창 · 샘플 창 — 화면 기준서 (DTME v0.15.0)

다른 프로그램(MOSCO 등)에서 같은 틀로 만들 때 쓰는 기준서입니다.
- 그림: Claude 디자인 캔버스 https://claude.ai/artifact/C4YHhA1vrZEKLp76BF4YY6 → 맨 위 `Auto` · `AutoPop` · `SampleDlg` 판
- 실제 코드(PySide6 / Qt): `app/dtme/ui_auto.py` (AUTO 창·프리셋 창·샘플 창·공통 부품), `app/dtme/ui_edit.py` (`open_auto`, `_auto_start`, `_auto_sample`, `SourceDelegate.paint`)

## 2. 메인 화면 소스 목록 [공통]

- 소스 열 맨 위 가운데 **[AUTO]**(빨강 88×32) → 바로 아래 3px 진행 막대(분석 파랑 / 렌더 빨강, 쉴 때 숨김) → 소스 목록
- 소스 줄 = 높이 그대로 한 줄: `이름(굵게) ············ C ◆3 프리셋이름`
  - 좁으면 **프리셋 이름만** `…` 으로 줄임(이름은 그대로)
  - 마우스를 올리면 툴팁: 경로 / 프리셋(직접·자동) / 인식 결과(직접 지정과 다를 때) / 출력
- 렌더 목록: 같은 중간 회색, 진행은 빨간 막대

## 3. AUTO 창 (1040×720) [공통 틀]

```
┌──────────────────────────────────────────────────────────────────────┐
│ ┌ 클립 목록 ───────────────────────┐  [        모두 자동        ]    │
│ │☑ 1025 1207  라이트·거북이 인식:… 1080│  라이트   [자동][물고기][산호초][거북이][다이버] │
│ │☑ 1025 1213 C 얕은·산호초 ◆3     세로│  얕은 수심 [자동][  …4개  ]   │
│ │☐ 1025 1240 C 자동               4K │  깊은 수심 [자동][  …4개  ]   │
│ │                                  │  기타          [블루워터][야간] │
│ │                                  │  ────────────────────────────   │
│ │                                  │  강도  [약|중|강]               │
│ │                                  │  출력  [1080|1440|4K|세로]      │
│ │                                  │  이름  [DTME    ] DTME_2026….mp4 │
│ │                                  │        ┌ 세부 정보(10개 값) ┐   │
│ └──────────────────────────────────┘        └────────────────────┘   │
│ ━━━━━━━━━━━━━━━━━ 진행 막대(가로 전체) ━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
│ 기존 값 [기존 보정 유지|기존 보정 무시]  [키프레임 유지|키프레임 자동] │
│ 이후   [자동 보정 후 바로 렌더|자동 보정 후 개별 보정]  [취소][샘플][시작] │
└──────────────────────────────────────────────────────────────────────┘
```

- **왼쪽 클립 줄**(28px, 한 줄): ☑(포함) · 이름 · C · 프리셋 이름 · 작은 회색 글씨(`인식: …` 직접 지정과 다를 때, `◆n` 키프레임 자동일 때, `분석 실패`) · 오른쪽 출력 칩
  - 체크 칸 클릭 = 포함/제외, 줄 클릭 = 선택(Ctrl·Shift 여러 개)
  - 분석 중 = 줄 배경이 진행만큼 `#5d7896` 으로 차오름
- **오른쪽 프리셋 격자**: 누르면 **선택한 클립**(없으면 전체)에 지정. [모두 자동] = 전체를 자동으로
  - 줄 맨 앞 [자동] = 그 줄 항목(장면)은 고정, 나머지(피사체)는 자동 인식
  - 버튼에 마우스 = 세부 정보 칸에 그 프리셋 값 / 아니면 선택한 클립에 들어갈 값
- **강도**는 전체 공통, **출력**은 선택한 클립(없으면 전체), **이름** = 렌더·샘플 파일 이름 머리(렌더 설정의 명칭과 같은 값)
- **세부 정보 칸**: 출력·이름 아래, 아래쪽 선에 맞춤. 제목(프리셋 이름) + 값 2열
- **아래**
  - 창을 열면 체크된 클립 분석을 바로 시작(가로 진행 막대 파랑)
  - 기존 값: `기존 보정 유지` = C 인 클립은 체크 해제(건너뜀) / `무시` = 덮어씀. `키프레임 유지` = 손으로 넣은 ◆ 그대로, 자동 키 안 넣음 / `키프레임 자동` = AUTO 가 만든 키로 바꿈
  - 이후: `바로 렌더` = 적용 → 소스마다 렌더 항목 1개 → 렌더 시작(막대 빨강) / `개별 보정` = 적용 후 창 닫고 반반 보기
  - [샘플] = 샘플 창 → 렌더 없이 반반 PNG 만 / [시작] = 저장폴더 묻기 → (분석이 덜 끝났으면 끝까지 기다림) → 적용(실행취소 1번)
  - 설정(강도·기존 값·키프레임·이후)은 다음에 열 때도 기억

[DTME] 격자 줄·칸 = 장면(라이트·얕은 수심·깊은 수심) × 피사체(물고기·산호초·거북이·다이버) + 기타(블루워터·야간), 세부 값 = 빨강·파랑·색조·채도·물빛·녹황·명암 S·디헤이즈·색/밝기 노이즈.
다른 프로그램은 자기 분류(예: 작업·장소·인원·각도·카메라)를 줄로, 값 이름을 자기 것으로 바꾸고 나머지 틀은 그대로.

## 4. 보정 탭 프리셋 창 (폭 540, 팝업) [공통 틀]

- 보정 패널 `[프리셋: 이름 ▾] [저장…]` 의 왼쪽 버튼을 누르면 버튼 아래에 뜸(바깥 클릭하면 닫힘)
- 내용 = AUTO 창 오른쪽과 같은 격자 + `강도` + 세부 정보 + 구분선 + 사용자 프리셋 버튼(`기본값` · 저장한 것들)
- 누르면 바로 적용하고 닫힘(현재 클립, 여러 개 선택했으면 모두). 기본·사용자 프리셋 = 고정값 / [모두 자동]·줄 [자동] = 그 클립 분석(추천) 후 적용 + 반반 보기
- 사용자 프리셋 우클릭 = 이름 바꾸기 · 지금 값으로 덮어쓰기 · 기본값으로 쓰기 · 삭제 / 저장은 패널의 [저장…]

## 6. RGB 그래프 도움 [DTME, 참고]

- RGB 버튼을 누를 때마다 `겹침 → 파레이드 → 끔` (켜짐 = 파랑)
- 목표선 5%·95% 점선, 끝에 붙어 뭉개지면 빨간 점, 목표선까지 못 가면 파란 점
- 그래프 바로 아래 [명암] [색 균형] (56×22)
