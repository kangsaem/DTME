## 2. 메인 화면 소스 목록 [공통]

- 소스 열 맨 위 가운데 **[AUTO]**(빨강 88×32) → 바로 아래 3px 진행 막대(분석 파랑 / 렌더 빨강, 쉴 때 숨김) → 소스 목록
- 소스 줄 = 높이 그대로 한 줄: `이름(굵게) ············ C ◆3 프리셋이름`
  - 좁으면 **프리셋 이름만** `…` 으로 줄임(이름은 그대로)
  - 마우스를 올리면 툴팁: 경로 / 프리셋(직접·자동) / 인식 결과(직접 지정과 다를 때) / 출력
- 렌더 목록: 같은 중간 회색, 진행은 빨간 막대

## 3. AUTO 창 (1040×720) [공통 틀]

- 테두리 없는 창 → **빈 바탕을 잡고 끌면 창 이동**(버튼·목록·입력란 위는 원래 동작). 렌더 설정·샘플 창도 같음
- 샘플 창: 저장폴더 · 크기 · 형식 · **배치 [나란히|위아래|좌우]**(기본 나란히 = 보정 전·후 전체 2장, 가로 영상은 위아래로 붙임) · 이름 · 붙이기

```
┌──────────────────────────────────────────────────────────────────────┐
│ ┌ 클립 목록 ───────────────────────┐  [기존 보정 유지][무시]  [키프레임 유지][자동] │
│ │                                  │  [        프리셋 자동        ]  │
│ │☑ 1025 1207  라이트 인식:산호   1080│  [ 라이트 ] [  산호  ] [ 얕은 수심 ] │
│ │☑ 1025 1213 C 산호 ◆3          세로│  [깊은 수심] [블루워터] [  야간   ] │
│ │☐ 1025 1240 C 자동               4K │                                 │
│ │                                  │                                 │
│ │                                  │  ────────────────────────────   │
│ │                                  │  강도  [약][중][강]             │
│ │                                  │  출력  [1080][1440][4K][세로]   │
│ │                                  │  LUT   [자동 (파일 정보)      ▾] │
│ │                                  │  이름  [DTME    ] DTME_2026….mp4 │
│ │                                  │  렌즈 보정   ━━━●━━━━━━━  40  │
│ │                                  │  흔들림 보정 ━━●━━━━━━━━  25  │
│ │                                  │        ┌ 세부 정보(10개 값) ┐   │
│ └──────────────────────────────────┘        └────────────────────┘   │
│ ━━━━━━━━━━━━━━━━━ 진행 막대(가로 전체) ━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
│                                                   [취소][샘플][보정만][보정+렌더] │
│                                                   └ 오른쪽 열(470) 안 오른쪽 ┘ │
└──────────────────────────────────────────────────────────────────────┘
```

- **[프리셋 자동]** = 고르기(실행 아님): 고른 클립(없으면 전체)의 프리셋을 자동 인식으로. 다른 프리셋 버튼과 같은 높이·모양(굵게 안 함)
- **왼쪽 클립 줄**(28px, 한 줄): ☑(포함) · 이름 · C · 프리셋 이름 · 작은 회색 글씨(`로딩 중 n%`, `인식: …` 직접 지정과 다를 때, `◆n` 키프레임 자동일 때, `분석 실패`) · 오른쪽 출력 칩
  - 체크 칸 클릭 = 포함/제외, 줄 클릭 = 선택(Ctrl·Shift 여러 개)
  - 분석 중 = 줄 배경이 진행만큼 `#5d7896` 으로 차오름. 영상을 막 넣었으면 파일 정보만 읽히면 바로 분석(재생용 프록시는 기다리지 않음)
- **오른쪽 프리셋 격자**: 누르면 **선택한 클립**(없으면 전체)에 지정
  - 버튼에 마우스 = 세부 정보 칸에 그 프리셋 값 / 아니면 선택한 클립에 들어갈 값
- **강도**는 전체 공통, **출력**은 선택한 클립(없으면 전체), **이름** = 렌더·샘플 파일 이름 머리(렌더 설정의 명칭과 같은 값)
- **세부 정보 칸**: 출력·이름 아래, 아래쪽 선에 맞춤. 제목(프리셋 이름) + 값 2열
- **오른쪽 맨 위**(프리셋 격자 위): [기존 보정 유지][기존 보정 무시] = C 인 클립 건너뜀/덮어씀 · [키프레임 유지][키프레임 자동] = 손으로 넣은 ◆ 그대로/AUTO 키로 교체
- **LUT [▾]**(출력 아래, 창 전체 하나): 자동 (파일 정보) = D-Log M 만 LUT, 일반·알 수 없음은 없음 / LUT 없음 / LUT 파일. 바꾸면 다시 분석. 줄 작은 글씨 `D-Log M` · `일반 · LUT 없음` · `알 수 없음 · LUT 없음` [DTME 전용: DJI 메타]
- **렌즈 보정·흔들림 보정** 슬라이더(0~100, 이름 아래): 체크된 클립 모두에 그 값. 다음에 열 때 기억
- **아래 줄**(제목 글자 없음) 오른쪽: [취소] [샘플(주황)] **[보정만(밝은 회색)]** = 값 넣고 창 닫고 반반 보기 · **[보정+렌더(빨강)]** = 값 넣고 소스마다 렌더 1개 + 렌더 시작
  - [보정만]·[보정+렌더] = 저장폴더 묻기 → (분석이 덜 끝났으면 끝까지 기다림) → 적용(실행취소 1번)
  - 설정(강도·기존 값·키프레임·렌즈·흔들림·마지막 실행 방식)은 다음에 열 때도 기억

[DTME] 격자 = [프리셋 자동] 한 줄 + 6개(라이트·산호·얕은 수심·깊은 수심·블루워터·야간) 2줄×3칸, 세부 값 = 빨강·파랑·색조·채도·물빛·녹황 빼기·명암 S·색/밝기 노이즈·물 노이즈(디헤이즈는 v0.16.2 에서 뺌).
다른 프로그램은 자기 분류(예: 작업·장소·인원·각도·카메라)를 줄로, 값 이름을 자기 것으로 바꾸고 나머지 틀은 그대로.

## 4. 보정 탭 프리셋 창 (폭 540, 팝업) [공통 틀]

- 보정 패널 `[프리셋: 이름 ▾] [저장…]` 의 왼쪽 버튼을 누르면 버튼 아래에 뜸(바깥 클릭하면 닫힘)
- 내용 = AUTO 창 오른쪽과 같은 격자 + `강도` + 세부 정보 + 구분선 + 사용자 프리셋 버튼(`기본값` · 저장한 것들)
- 누르면 바로 적용하고 닫힘(현재 클립, 여러 개 선택했으면 모두). 기본·사용자 프리셋 = 고정값 / [프리셋 자동]·줄 [자동] = 그 클립 분석(추천) 후 적용 + 반반 보기
- 사용자 프리셋 우클릭 = 이름 바꾸기 · 지금 값으로 덮어쓰기 · 기본값으로 쓰기 · 삭제 / 저장은 패널의 [저장…]

## 6. RGB 그래프 도움 [DTME, 참고]

- RGB 버튼을 누를 때마다 `겹침 → 파레이드 → 끔` (켜짐 = 파랑)
- 목표선 5%·95% 점선, 끝에 붙어 뭉개지면 빨간 점, 목표선까지 못 가면 파란 점
- 그래프 바로 아래 [명암] [색 균형] (56×22)
