# DTME (Diving Tour Movie Editor)

DJI Osmo Action 4 **D-Log M 4K60** 영상을 빠르게 컷 → 보정 → 출력하는 Windows용 도구. 설치 없이 폴더째 실행.

- 프록시(960px, 모든 프레임 키프레임)로 컷 지정 → **원본 4K**에 같은 프레임 위치로 적용
- 보정: LUT · R/B 게인 · 마스터 커브(포인트 5개) · Hue 회전(±15°) · 노이즈 제거 · 샤픈
- 배속: 2x / 1x / ½x (오디오는 음 높이 유지하며 속도 변경)
- 타임라인: 화면 전환(구간 표시·끝 끌어 길이) · 글자(크기 16~600) · 사각형(글자 배경) · 이미지 · 음악
- 출력: 1920×1080 또는 1080×1920(중앙 크롭), 29.97fps, H.264 / 스틸은 4K 16bit TIFF

## 받기 · 실행

1. GitHub 저장소 → **Actions** → 최신 "Windows build" → 아래 **Artifacts**의 `DTME-windows` 다운로드
2. 압축을 풀고 `DTME.exe` 실행 (C:\Program Files 처럼 쓰기 제한된 폴더는 피하기)
3. `luts` 폴더에 LUT(.cube) 넣기 — 또는 보정 탭의 "LUT 추가…"

폴더 안 구성: `DTME.exe`, `bin/ffmpeg.exe·ffprobe.exe`, `luts/`, `cache/`(프록시·미리보기, 지워도 다시 만들어짐), `settings.json`(새 프로젝트 기본값)

## 화면

상단: **새 프로젝트 · 저장하기 · 불러오기 · 실행취소(Ctrl+Z)** / 탭: **편집 · 보정** · **렌더(설정)**

편집 · 보정 화면: 소스 | 모니터·타임라인 | 보정 | 렌더 리스트

- **샘플**: 현재 클립 전체(인/아웃과 무관)에서 고르게 6장을 PNG로 만들어 오른쪽 아래에 표시. 클릭 = 모니터에 크게(이동·재렌더 없음), 더블클릭 = PNG 열기

### 자동 창 (v0.17.0)
프로그램을 켜면 뜨는 시작 창의 **AUTO**, 편집 창 소스 목록 맨 위 빨간 **AUTO** = 같은 **자동 창**.
- 왼쪽 = 영상 목록(여행별 묶음 `기간 · 지명` · 체크 = 이번 편집에 넣음 · Del = 목록에서 제거 · 방향 다른 클립 `세로`). 영상·폴더·음악·사진·다이빙 기록(FIT·DTMD)을 창 어디든 끌어다 놓기 · 우클릭 = 파일 추가 / 폴더 추가 / 프로젝트 열기(프로젝트 파일 = 바로 편집 화면)
- 오른쪽 아래 = 단계 4줄 **[보정] [편집] [음악] [렌더]**: 체크 칸 = 켬/끔 · 줄 = 펼쳐서 설정(한 번에 하나) · 마지막 선택을 기억(렌더 기본 = 끔)
  - 보정 = 프리셋 자동/지정 · 강도 · 기존 보정 · 키프레임 · LUT · 렌즈·흔들림 보정
  - 편집 = 전체 길이(분:초, 시작·끝 화면 포함 파일 길이 · [곡 길이에 맞춤] 체크 = 올린 곡 1~2개 길이로) · 날짜 바 · LOG 수심 그래프 · 시작/끝 화면 · 지명 · 끝 문구
  - 음악 = 박자우선 · 기본 음악도 같이 쓰기(편집을 켰을 때만)
  - 렌더 = 출력 크기 · 품질(고화질/보통/작게) · 저장 폴더 · 이름 · 프로젝트 저장
- **[AUTO]** 를 누르기 전에는 파일 정보만 읽음(분석·프록시 없음). 누르면 이 창 안에서 단계별 진행(막대 하나 · [취소] · [−])
  - 렌더 켬 = 편집 창·프록시·미리보기 없이 끝까지 → 완료 팝업 [폴더 열기] [편집 화면] [닫기]. 편집 켬 = 타임라인 1편, 편집 끔 = 클립마다 따로
  - 렌더 끔 = 쓰는 클립 프록시·전환 미리보기를 미리 만든 뒤 편집 화면
  - 단계를 하나도 안 켜고 [AUTO] = 그냥 편집 화면으로
- 가로·세로 영상이 섞이면 출력 = 많은 쪽(같으면 가로), 다른 방향은 가운데 잘라 넣음(목록 아래 알림 한 줄)
- 보정 패널 `[프리셋: … ▾]` = 프리셋 창(고르고 [적용]). 색 통계로 판단하는 출발점입니다(AI 아님)

### 줌 + 위치 (v0.17.0)
타임라인에서 컷을 고르면 보정 패널 **렌즈 · 흔들림 · 줌** 묶음의 **줌** 슬라이드바가 켜짐: ×1.00 ~ 한도(원본÷출력: 4K→1080 = ×2 · 4K→1440 = ×1.5 · 1080→1080 = 못 씀), ×1.0·×1.5·×2.0 에서 붙음, 이름을 누르면 ×1.00. 타임라인 전부 고름(Ctrl+A) = 모든 컷.
모니터 화면을 끌면 위치(끄는 동안 원본 전체가 흐리게 + 점선 상자), 더블클릭 = 가운데. 세로 클립을 가로 영상에 넣은 컷은 줌 없이도 위아래로 끌 수 있음. 컷 단위라 자동 편집을 다시 하면 사라짐.

### 렌더
- 렌더 중 = **렌더** 버튼이 전체 진행 막대(`3/35 · 42%`, 영상 길이 기준) · 창 제목 · Windows 작업 표시줄 아이콘 막대(실패 있으면 빨강). 끝나면 팝업(완료·실패·걸린 시간, [폴더 열기][확인]) + 창이 뒤에 있으면 아이콘 깜빡임
- 출력 이름 = `접두어_2026 1028 1144.mp4`(소스 목록처럼 연도·월일·시간 띄움)
- 컷 1개짜리 항목(20초 이상, 흔들림 보정 없음)은 조각내 동시에 렌더 후 이어 붙임(결과 같음). HDD·SD 원본은 렌더 전에 순서대로 미리 읽음(최대 32GB, `settings.json` `precache_gb`)
- GPU 쓰는 작업 동시 최대 6(`gpu_jobs`), 인코더 개수 한계에 걸리면 줄여 기억(`nvenc_max`)
**▼** = 소스 목록에서 선택한 소스를 렌더 리스트로(소스마다 1개, 지금 값 · 완료된 소스는 건너뜀 · 소스 우클릭 [렌더 리스트로] 도 같음) · ⚙ 인코더 · 비트레이트 · 디코딩 · 저장폴더 / 렌더 리스트(우클릭·Del 삭제, 다시 렌더 대기로) / **렌더** 버튼

### 프록시란
편집 화면 재생용 가벼운 복사본(960px, 모든 프레임이 기준 프레임). 4K 원본은 0.5초마다 기준 프레임이 있어 한 프레임씩 넘기면 느리기 때문에 만듦. 최종 렌더는 항상 원본을 사용.

## 보정 규칙

- 처리 순서 고정: 노이즈 → LUT → R/B 게인 → 커브 → Hue → 샤픈
- 영상은 1080으로 줄인 뒤 노이즈 제거(빠름), 스틸은 4K 그대로 처리(노이즈 '강' 선택 가능)
- **기본값** → **클립**(바꾼 항목만 덮어씀, ● 표시) → **스틸**(클립 위에 추가) 순서로 합쳐짐
- 프레임 이동·스크럽은 RAM 캐시(프록시를 구간 단위로 미리 디코딩, 상한 = 메모리의 25%·최대 64GB, `settings.json` 의 `ram_cache_gb` 로 변경)
- 미리보기는 최종 렌더와 같은 FFmpeg 처리로 만듦 (실측 평균 차이 1% 미만, 4:2:0 압축 차이)
- 수중 영상의 파란 기운은 Hue가 아니라 **R 게인↑ / B 게인↓** 로 잡는 것이 자연스러움
