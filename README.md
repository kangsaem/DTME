# DTME (Diving Tour Movie Editor)

DJI Osmo Action 4 **D-Log M 4K60** 영상을 빠르게 컷 → 보정 → 출력하는 Windows용 도구. 설치 없이 폴더째 실행.

- 프록시(960px, 모든 프레임 키프레임)로 컷 지정 → **원본 4K**에 같은 프레임 위치로 적용
- 보정: LUT · R/B 게인 · 마스터 커브(포인트 5개) · Hue 회전(±15°) · 노이즈 제거 · 샤픈
- 배속: 2x / 1x / ½x (오디오는 음 높이 유지하며 속도 변경)
- 출력: 1920×1080 또는 1080×1920(중앙 크롭), 29.97fps, H.264 / 스틸은 4K 16bit TIFF

## 받기 · 실행

1. GitHub 저장소 → **Actions** → 최신 "Windows build" → 아래 **Artifacts**의 `DTME-windows` 다운로드
2. 압축을 풀고 `DTME.exe` 실행 (C:\Program Files 처럼 쓰기 제한된 폴더는 피하기)
3. `luts` 폴더에 LUT(.cube) 넣기 — 또는 보정 탭의 "LUT 추가…"

폴더 안 구성: `DTME.exe`, `bin/ffmpeg.exe·ffprobe.exe`, `luts/`, `cache/`(프록시·미리보기, 지워도 다시 만들어짐), `settings.json`(새 프로젝트 기본값)

## 작업 순서

1. **편집 탭** — 영상 추가(여러 개, 끌어다 놓기 가능) → 프록시 자동 생성 → 재생하며 구간 지정
2. **보정 탭** — 대상 선택(기본값 / 클립 / 스틸) → 샘플 5장 보며 조절
3. **출력 탭** — 가로/세로, 소스별 1개 또는 이어붙이기 → 영상 렌더 / 스틸 출력

## 편집 단축키

| 키 | 동작 |
|---|---|
| Space | 재생/정지 |
| J / K / L | 뒤로 / 정지 / 앞으로 (반복하면 2·4·8배) |
| ← / → | 1프레임 이동 · Shift = 1초 |
| I / O | 컷인 / 컷아웃 (구간 선택 중이면 그 구간 수정) |
| 1 / 2 / 3 | 2x / 1x / ½x (구간 선택 중이면 그 구간, 아니면 다음 구간) |
| Del / Esc | 선택 구간 삭제 / 선택 해제 |
| S | 스틸 표시 (4K TIFF 출력 대상) |
| G | 보정 샘플 지정 (최대 5장) |
| 마우스 휠 | 타임라인 확대/축소 |

## 보정 규칙

- 처리 순서 고정: 노이즈 → LUT → R/B 게인 → 커브 → Hue → 샤픈
- 영상은 1080으로 줄인 뒤 노이즈 제거(빠름), 스틸은 4K 그대로 처리(노이즈 '강' 선택 가능)
- **기본값** → **클립**(바꾼 항목만 덮어씀, ● 표시) → **스틸**(클립 위에 추가) 순서로 합쳐짐
- 미리보기는 최종 렌더와 같은 FFmpeg 처리로 만듦 (실측 평균 차이 1% 미만, 4:2:0 압축 차이)
- 수중 영상의 파란 기운은 Hue가 아니라 **R 게인↑ / B 게인↓** 로 잡는 것이 자연스러움
