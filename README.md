# DTME (Diving Tour Movie Editor)

DJI Osmo Action 4 **D-Log M 4K60** 영상을 빠르게 컷 → 보정 → 출력하는 Windows용 도구. 설치 없이 폴더째 실행.

- 프록시(960px, 모든 프레임 키프레임)로 컷 지정 → **원본 4K**에 같은 프레임 위치로 적용
- 보정: LUT · R/B 게인 · 마스터 커브(포인트 5개) · Hue 회전(±15°) · 노이즈 제거 · 샤픈
- 배속: 2x / 1x / ½x (오디오는 음 높이 유지하며 속도 변경)
- 출력: 1920×1080 또는 1080×1920(중앙 크롭), 29.97fps, H.264 / 스틸은 4K 16bit TIFF

## 받기 · 실행

1. GitHub 저장소 → **Actions** → 최신 "Windows build" → 아래 **Artifacts**의 `DTME-windows` 다운로드
2. 압축을 풀고 `DTME.exe` 실행 (C:\Program Files 처럼 쓰기 제한된 폴더는 피하기)
3. `luts` 폴더에 LUT(.cube) 넣기 — 또는 보정 탭의 "LUT 추가…"

폴더 안 구성: `DTME.exe`, `bin/ffmpeg.exe·ffprobe.exe`, `luts/`, `cache/`(프록시·미리보기, 지워도 다시 만들어짐), `settings.json`(새 프로젝트 기본값)

## 화면

상단: **새 프로젝트 · 저장하기 · 불러오기 · 실행취소(Ctrl+Z)** / 탭: **편집 · 보정** · **렌더(설정)**

편집 · 보정 화면: 소스 | 모니터·타임라인 | 보정 | 렌더 리스트

### 편집 · 보정
| 위치 | 내용 |
|---|---|
| 왼쪽 **소스** | 영상 추가(여러 개·끌어다 놓기). 목록 즉시 생성, 분석·프록시는 뒤에서(진행 막대). 클릭하면 모니터에 표시 |
| 가운데 **모니터** | 재생 중 = 프록시 / 정지·이동 = 프록시 프레임 즉시 → 0.35초 뒤 원본 기준 보정 화면 |
| 모니터 바로 아래 **소스 바** | 현재 클립 전체 길이. 인/아웃 구간을 배속 색으로, 배속 글자(x2·x1·x1/2), 왼쪽 위 삼각형 **E**(기본값) / **C**(클립 보정 있음) |
| 버튼 | 재생 계열(가운데) · [ 컷인 · 컷아웃 ] · IO 해제 · 삭제 · x2/x1/x1/2 · 스틸 · 샘플 |
| **▼ / ▶** | ▼ = 인/아웃 구간을 타임라인 끝에 붙임 · ▶ = 렌더 리스트로 바로(영상 1개) |
| **타임라인** | 컷을 결과 길이(배속 반영)대로 이어 표시. 클릭 선택 · 드래그로 순서 변경 · 더블클릭 = 소스 열기 · 확대 슬라이더 · 아래 눈금 = 결과 시간 · 빨간 점선 = 30초. 전체 삭제 / 렌더 리스트로 ▶ |
| 오른쪽 **보정** | 기본값 / 현재 클립 · 가로/세로 · 오디오 · LUT · R · B · Hue · 샤픈 · 디노이즈 · 커브(리셋) · 기본값으로 저장 · 샘플 6장 썸네일 |

- **스틸**: 누르면 현재 프레임을 4K 16bit PNG로 바로 저장(렌더 탭의 저장폴더)
- **샘플**: 현재 클립 전체(인/아웃과 무관)에서 고르게 6장을 PNG로 만들어 오른쪽 아래에 표시. 클릭 = 모니터에 크게(이동·재렌더 없음), 더블클릭 = PNG 열기

### AUTO (v0.15)
소스 목록 맨 위 빨간 **AUTO** → 큰 창. 왼쪽 클립 목록(체크 = 포함), 오른쪽 프리셋(모두 자동 · 장면별 자동 · 기본 14개) · 강도 · 출력 · 이름 · 세부 값.
아래 `기존 값`(기존 보정 유지/무시 · 키프레임 유지/자동) · `이후`(바로 렌더 / 개별 보정) · [취소] [샘플] [시작].
- [샘플]: 클립마다 반반(왼쪽 원본 · 오른쪽 보정) 6장을 PNG/JPG 로만 저장(크기·형식·이름 설정)
- [시작]: 저장폴더를 고르면 보정 적용 → 바로 렌더(소스마다 1개) 또는 개별 보정
- 보정 패널 `[프리셋: … ▾]` = 같은 모양의 프리셋 창(누르면 바로 적용, 모두 자동 = 추천 보정)
- 색 통계로 판단하는 출발점입니다(AI 아님). 피사체는 산호초만 추정, 나머지는 직접 고르기

### 렌더
인코더 · 비트레이트 · 디코딩 · 저장폴더 / 렌더 리스트(우클릭·Del 삭제, 다시 렌더 대기로) / **렌더** 버튼

### 프록시란
편집 화면 재생용 가벼운 복사본(960px, 모든 프레임이 기준 프레임). 4K 원본은 0.5초마다 기준 프레임이 있어 한 프레임씩 넘기면 느리기 때문에 만듦. 최종 렌더는 항상 원본을 사용.

## 단축키 (버튼에 마우스를 올리면 표시)

| 키 | 동작 |
|---|---|
| Space | 재생/정지 |
| J / L | 2배속 뒤로 / 앞으로 (다시 누르면 정지) |
| ← / → | 1프레임 · Shift = 1초 |
| I 또는 [ / O 또는 ] | 컷인 / 컷아웃 |
| Esc | 인/아웃 해제 |
| 1 / 2 / 3 | x2 / x1 / x1/2 |
| ↓ | 타임라인으로 |
| Enter | 렌더 리스트로 |
| Del | 타임라인에서 선택한 컷 삭제 |
| S / G / B | 스틸 PNG / 샘플 6장 / 보정 전 보기 |
| Ctrl+Z / Ctrl+S / Ctrl+O | 실행취소 / 저장 / 불러오기 |

물리 키 위치로 인식하므로 한/영 상태와 관계없이 동작합니다.

## 보정 규칙

- 처리 순서 고정: 노이즈 → LUT → R/B 게인 → 커브 → Hue → 샤픈
- 영상은 1080으로 줄인 뒤 노이즈 제거(빠름), 스틸은 4K 그대로 처리(노이즈 '강' 선택 가능)
- **기본값** → **클립**(바꾼 항목만 덮어씀, ● 표시) → **스틸**(클립 위에 추가) 순서로 합쳐짐
- 미리보기는 최종 렌더와 같은 FFmpeg 처리로 만듦 (실측 평균 차이 1% 미만, 4:2:0 압축 차이)
- 수중 영상의 파란 기운은 Hue가 아니라 **R 게인↑ / B 게인↓** 로 잡는 것이 자연스러움
