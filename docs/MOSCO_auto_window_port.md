# DTME 이식 지시 — 시작 창 · AUTO 창 개편 (MOSCO v0.7.92~0.7.96, 2026-11-17)

MOSCO에서 사용자와 확정한 시작 창 / AUTO 창 변경을 DTME에도 같게 맞추기 위한 메모입니다.
DTME에 없는 기능(AE·샘플·4444 알파 등)은 **"DTME에 해당 기능이 있으면"** 기준으로 적용하고, 모르면 사용자에게 먼저 물어볼 것.
참고 코드: `kangsaem/MOSCO` 의 `app/mosco/ui_start.py`, `app/mosco/ui_auto.py` (v0.7.96), 변경 이력은 MOSCO `HANDOFF.md`.

---

## 1. 시작 창

| 항목 | 이전 | 지금(확정) |
|---|---|---|
| 버튼 | [AUTO] + [편집] | **[AUTO] 하나** (160×48, 빨강, 굵게) |
| [AUTO] 누르면 | 파일…/폴더… 메뉴 → 고른 파일로 AUTO 창 | **아무것도 묻지 않고 빈 AUTO 창** |
| [편집] | 빈 편집 화면 | **삭제**. 편집 화면 가는 길 = AUTO 창 [AUTO] 완료 · 프로젝트 열기 · 자동 저장 복구 |
| AUTO 창 [취소] | 시작 창으로 | 시작 창으로 + **넣었던 영상 버림**(새 빈 프로젝트) → 다음에도 빈 목록 |

- 그림: 정사각형 400×400(파일 800×800), 위 왼쪽 제목·버전(흰 글자), 오른쪽 위 ✕. **그림·그라데이션은 MOSCO 전용**(DTME는 자기 그림 사용). 참고로 MOSCO는 밝은 하늘 위 흰 글자가 안 보여 **그림 왼쪽 절반·위 90px에 파랑 그라데이션**(`rgba(30,120,230,235)` → 55% 지점 120 → 투명, 마우스 통과)을 제목 아래 깔았음. DTME 그림도 제목이 밝은 바탕 위면 같은 방식 고려.
- 창 크기 400×560, 테두리 없음, 끌어서 이동(그대로).

## 2. AUTO 창 — 아래 버튼 줄

- 순서: **`[취소][샘플][AE][AUTO]`**, 모두 **88×32**.
- **[보정+렌더] 삭제** — AUTO 창에서 바로 렌더하지 않음. 렌더는 편집 화면 [렌더]에서만. 함께 지운 것: AUTO 창 안 렌더 진행 표시, 렌더 완료 팝업([폴더 열기]/[확인]), 시작 창의 '렌더 끝나면 프로그램 종료'.
- **[보정+편집] → 이름 [AUTO]**, 색 **빨강**(시작 창 AUTO와 같음). 동작 그대로: 적용 + 분석·트랙까지 끝내고 편집 화면으로.
- [샘플](주황)은 [AE](빨강) **왼쪽**으로.
- 저장된 설정에 `auto_after = "render"` 가 남아 있어도 무시(항상 편집 화면/AE).

## 3. AUTO 창 — 출력

- **완성본 = ProRes 422 HQ 고정.** AUTO 창의 **'출력' 줄(422 HQ/422/LT) 삭제**, 클립 줄 오른쪽 출력 칩(HQ/+α) 삭제.
- ⚙ 렌더 설정의 ProRes 종류 선택도 삭제(체크칸 'ProRes 422 HQ' 만). 예전 설정·프로젝트에 422/LT가 있어도 렌더는 HQ.
- 예외: 블러 오버레이 **ProRes 4444 알파**(MOSCO 전용)·검수 H.264 는 그대로.

## 4. AUTO 창 — 빈 목록에서 시작 · 추가 방법

- 시작 창에서 열면 **목록이 빈 채로** 뜸(편집 화면에서 열 때는 지금처럼 소스 전체, 소스가 없어도 열림).
- **빈 목록 안내**: 목록 가운데 두 줄, 목록이 비었을 때만 보이고 하나라도 들어가면 사라짐.
  - 문구: `파일이나 폴더를 끌어다 놓으세요` / `또는 우클릭해서 추가하세요`
  - 색 `#6f6f6f`, **14px**, 가운데 정렬, 마우스 클릭 통과
  - ※ "화면에 설명 문구 넣지 말 것" 규칙의 **예외(빈 목록 한정, 사용자 요청)**
- **우클릭 메뉴**(목록 어디서나, 줄 위 포함):
  - `파일 추가…` / `폴더 추가…` / ─(구분선) / `프로젝트 열기…`
  - 글자 **14px**, 항목 여백 `6px 22px`, 구분선 1px `#444`(좌우 8px 여백). (예전 12px·4px 18px는 작다고 함)
- **끌어다 놓기**: AUTO 창 어디에 놓아도 됨. 영상 파일 · 폴더(하위 폴더 포함 영상) · 프로젝트 파일.
- 넣을 때마다 줄이 추가되고 창 높이가 줄 수에 맞게 다시 맞춰짐(최대 20줄, 넘으면 목록만 스크롤). 첫 추가 시 첫 줄 선택.
- 측정·분석·AE 진행 중에는 추가 안 받음.
- 폴더에 영상이 없으면 AUTO 창 상태 줄에 빨간 글자 "이 폴더에 영상이 없습니다".

## 5. 프로젝트 파일 처리

- 프로젝트 파일은 **목록에 넣지 않음** → AUTO 창을 닫고 **그 프로젝트로 바로 편집 화면**.
  - 이유: AUTO 창 기본값이 '기존 보정 무시'라, 목록에 넣고 [AUTO]를 누르면 손으로 고친 편집이 덮어써짐.
- 시작 창에서 연 AUTO 창에 영상이 이미 있으면: 팝업 "목록을 비우고 프로젝트를 엽니다" `[취소][열기]`.
- 편집 화면에서 연 AUTO 창이면: 기존 '저장할까요' 확인 후 열기.
- 불러오기 실패 시 경고만 띄우고 AUTO 창 유지.

## 6. 테스트(MOSCO에서 넣은 것 — DTME도 같은 취지로)

- 시작 창에 [편집] 없음.
- [AUTO] → 빈 AUTO 창 · 안내 글자 보임 → 영상+폴더 추가 → 줄 수 = 클립 수 · 안내 사라짐.
- 프로젝트 파일 놓기 → AUTO 창 닫힘 · 편집 화면 보임 · 그 프로젝트가 열림.
- AUTO 창 버튼 순서 = [취소][샘플][AE][AUTO], [보정+렌더] 없음.
- 완성본 렌더 결과 ProRes profile = HQ.

## 7. 실기 미확인(MOSCO도 아직)

- 윈도우 탐색기에서 실제 끌어다 놓기, 메뉴·안내 글자 14px 체감, 그라데이션 색(윈도우 글꼴 차이).
